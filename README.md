# Setup Studio

A 3D gaming-bedroom designer and PC builder that runs in the browser.

- Fully customizable room: size, wall and floor styles, day/night lighting, ceiling RGB LEDs
- Drag-and-drop furniture, monitors, keyboards, mice, consoles, neon signs, LED panels, posters (or your own images)
- PC Builder with ~1,950 parts (2012 → today), compatibility checks, power draw, price and performance rating
- The PC in the room is built from your chosen parts — glass panel, GPU, RAM, cooler and spinning RGB fans
- Autosaves in your browser; copy/paste layout codes to back up or move a room

## Run it

Open `index.html` in a browser, or turn on **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root) and visit
`https://consis300.github.io/Setup-Studio/`.

Built with [three.js](https://threejs.org/) (loaded from a CDN).
